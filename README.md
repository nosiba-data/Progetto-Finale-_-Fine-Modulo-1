Analisi del patrimonio ricettivo della Regione Marche — pulizia dati con Power Query, maschera di ricerca in Excel, statistica descrittiva, probabilità, inferenza, correlazione e regressione sui prezzi medi delle città.
# Analisi Patrimonio Ricettivo - Regione Marche

## File
- `Progetto Fine Modulo_Analisi del Patrimonio Ricettivo le Marche_RV` — file Excel completo con tutti gli esercizi (18)
- `Presentazione Progetto fine Modulo - Analisi del Patrimonio Ricettivo le Marche ` — presentazione PDF sui passaggi di dati

## Struttura del file Excel
- Indici: riepilogo del esercizi  
- Pulizia dati (Power Query): Strutture ricettive_Pulito_M 
- RICERCA: maschera di ricerca struttura, gli esercizi in questo foglio sono stati compilati dal foglio Strutture ricettive_Pulito_RAW
- Prezzi_Medi: statistica, probabilità, inferenza
- Conteggio strutture: Raggruppa (power Query)
- Correlazione: correlazione e regressione
- Dashboard: riepilogo del progetto
